# Python 100 Days Challenge

東京都市大学 電気電子通信工学科

プログラミングとソフトウェア開発の学習記録です。
100日間、毎日PythonやGit/GitHubを使ってアプリを作成し、GitHubに公開していきます。

## 学習目標

Pythonの基礎を身につける
Git / GitHub を使った開発に慣れる
Webアプリ開発（React・TypeScript）へ進む
就職活動で公開できるポートフォリオを作る
